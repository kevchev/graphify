# Generac Guardian 18kW — "El Niño winter" promo for Gardenland Power Equipment

A 1080p / 30 fps / 51-second narrated motion-graphics promo for the Generac Guardian® 18kW home standby
generator (model 7228), sold by Gardenland Power Equipment, Campbell CA, ahead of the strong El Niño winter
of 2026–27.

**Deliverable:** `output/generac-18kw-el-nino-promo.mp4` (H.264 + AAC, 1920×1080, stereo, −14 LUFS)

This is a ground-up rebuild of the 34-second text-and-music piece (`generac_18kw_v5_16x9.mp4`) made in the
Gardenland work account. Every on-screen fact is the same verified wording from that project's claims
register; what changed is the execution:

| | v5 (work account) | This cut |
|---|---|---|
| Narration | none | 8 lines, Kokoro-82M voice, ducked music bed |
| Type | rise-and-fade lines | mask-reveal line builds, scale pops, slide-outs on every cut |
| Numbers | static | 83% and $5,859.95 count up, probability bar fills |
| Weather | static plates | slow camera push on every plate, two-layer rain, lightning flashes |
| The turn | lit-house plate cut in | dark house → windows bloom on, with a low thump |
| Product | static cutout | 3-D turn-in, light sweep across the enclosure, drop shadow, slide-out carrier |
| Phone | static mock | phone slides up, live Mobile Link™ status card with pulsing ring, headline swap |
| Logo | rise | green line draw → logo wipes open → light sweep → tagline and CTA pill |

## Assets and rights

- Photo plates (`bg-storm`, `bg-dark`, `bg-lit`) were generated with Canva's image generator on Kevin's Canva
  account on 16 Oct 2026 for this campaign (no people, no marks). `house_dark.jpg` and `house_glow.png` are
  derived from `bg-lit.jpg` by `render/prep_assets.py` (windows darkened; warm bloom mask). Licence: Canva's
  terms for AI-generated content on that account.
- Product render `generac-7228.png`: Generac's product image as used on gardenland.com (downloaded 16 Oct
  2026 with the owner's OK), upscaled 2× with EDSR and cropped. Generac's own image CDN was not reachable
  from the build environment, so no additional Generac photography was used. Generac®, Guardian® and
  Mobile Link™ are Generac trademarks; the "GENERAC" word on the phone mock is typed, not the logo.
- Gardenland logo: `assets/img/gardenland-logo-white-green.svg`, as supplied, never redrawn.
- Rain sprites `rain_far.png` / `rain_near.png`: generated by `render/prep_assets.py`.
- Music: "Cinemato" from the effacestudios Royalty-Free-Music-Pack (CC0 1.0, public domain). Chosen by its
  loudness envelope, not by ear — have a human listen before airing.
- Sound hits (lights-on thump, product whoosh): synthesized in `render/mix.py` with ffmpeg.
- Narration: Kokoro-82M (Apache-2.0) via sherpa-onnx, voice `am_michael`. Script in `audio/narration-script.json`.
- Fonts: Barlow / Barlow Condensed and Lato (SIL OFL), self-hosted in `assets/fonts`.

## How it is built

```
render/composition.html   deterministic motion-graphics timeline: window.seek(t) sets every style for time t
render/render.js          Playwright screenshots one PNG per frame (frame ranges for parallel workers)
render/stills.js          review stills at chosen times
render/prep_assets.py     derives the dark-house plate, window bloom layer and rain sprites
render/tts.py             narration with Kokoro (KOKORO_DIR=<model dir>)
render/mix.py + mix.json  narration placement, EQ/compression, ducked music, hits, loudness normalization
audio/soundtrack.wav      final mixed soundtrack
```

Rebuild:

```bash
python3 render/prep_assets.py
KOKORO_DIR=<kokoro-en-v0_19> python3 render/tts.py <scratch>/gvo
SCRATCH=<scratch with gvo/ and music/> python3 render/mix.py
node render/render.js render/composition.html frames 30 51            # or split ranges across workers
ffmpeg -framerate 30 -i frames/f%05d.png -i audio/soundtrack.wav \
  -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p -c:a aac -b:a 192k -shortest output/generac-18kw-el-nino-promo.mp4
```
